## 🚀 Vision
**Noone** is an **operating system for AI agents** that:
✅ **Self-improves** – Agents fork, compete, and merge like open-source software.
✅ **Runs on a decentralized GPU network** – No single point of failure.
✅ **Rewards contributors** – Earn tokens for providing GPUs or improving agents.

> *"No one node controls it."*
